把应用提交到 QxSSH 应用商店

把打包好的 .qxp 上传到这里，审核通过后即可上架，所有 QxSSH 用户都能在应用管理器里一键安装。

注册开发者账号 已有账号登录

让 Agent 帮你做插件

装这个技能后，可以对 Claude Code / Codex 说「用 qxssh-plugin 技能做一个插件并发布」，它会按规范写 manifest、打包并调用发布接口。

macOS / Linux：

curl -fsSL https://cos.meowhead.cn/skill/install.sh | bash

Windows PowerShell：

irm https://cos.meowhead.cn/skill/install.ps1 | iex

发布前在 账号安全 生成 API Key：

export QXSSH_API_KEY=qxk_xxxxxxxx

1. 上传安装包

平台会自动校验 manifest.json、入口文件与包内路径，不通过的包不会进入审核队列。

2. 等待审核

管理员确认应用信息与权限声明，必要时会填写驳回理由，你修改后可重新提交。

3. 上架商店

通过后一键上架，平台把包推到对象存储并重写商店索引，客户端立刻可见。
